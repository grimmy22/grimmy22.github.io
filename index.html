§01 — cognitive-fatigue estimation
Patent filed · IPR0003546P

Behavioural Entropy Engine

A deterministic, model-free engine that estimates cognitive fatigue from inter-keystroke timing alone — no ML model, no stored keystrokes, every number traceable by hand. A kernel-level daemon reads raw keypress events through non-blocking syscalls into a mutex-guarded buffer, then computes Shannon entropy across five temporal bins plus sliding-window mean, variance, entropy rate, and entropy acceleration to classify typing / thinking / idle in real time.

§03 — real-time ingestion & visualization

OrbitWatch

A production-style pipeline for tracking data: automated ingestion from external APIs, a custom C++ parser (libsgp4, nlohmann/json) computing derived orbital metrics, and MongoDB persistence behind a paginated REST API built to keep query latency flat as the dataset keeps growing. The frontend adds searchable, infinite-scroll tables and a real-time 3D layer with raycasting for interactive queries.
